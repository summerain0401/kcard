# almanac 风格宪法

> 设计部交付物。本文件定义**什么不可违反**;可自由搭配的参数及其取值域见同目录 `space.json`。
> 2026-07-27 新建,kcard 的第二套风格。

## 一、这套风格是什么

十九世纪博物学图鉴 / 百科全书的印刷品质感。米色纸底、深墨横排衬线标题、
学术罗马编号、双线分隔、标本式居中构图,以及本风格的标志性元素——
**从主体引出的细线标签**。

视觉张力来自**印刷工艺的克制与秩序**,不来自对比度或特效。
适用于「一个主体 + 若干信息块」的百科式知识点,与 `editorial-mono`
覆盖同一类内容但气质相反:一个是暗夜画册,一个是纸本图鉴。

## 二、构成要素(缺一即不成立)

| # | 要素 | 现行实现 |
|---|---|---|
| E1 | **米色纸底**,须有暖色相,非纯白亦非中性灰 | HSL 明度 0.88–0.94,色相 30–50°,低饱和 |
| E2 | **纸纹肌理** | 分形噪声 + 极淡横向纹理,`multiply` 混合 |
| E3 | **横排衬线大标题** | 与 editorial-mono 的竖排形成结构性对比 |
| E4 | **标本式主体** | 居中,四周留白,下方一道基线代替展台 |
| E5 | **引线标签** | 自主体边缘水平引出细线 + 端点圆点 + 衬线小字 |
| E6 | **学术罗马编号** | 章节编号用 `I. II. III.`,非阿拉伯数字 |
| E7 | **双线分隔** | 章节间一粗一细两道线,图鉴版式的典型做法 |
| E8 | **页脚学名行** | 拉丁学名 + 页码感的编号 |

## 三、禁则(硬约束,机器可校验)

| # | 禁则 | 判据 | 理由 |
|---|---|---|---|
| H1 | 底色必须是米色纸调 | 纸色 HSL `L ∈ [0.86, 0.95]`,`S ∈ [0.04, 0.22]`,`H ∈ [25, 55]` | 纯白像 PPT,中性灰像草稿,暖色纸才是印刷品 |
| H2 | 用色必须朴素 | accent 饱和度 `≤ 0.60`,明度 `≤ 0.65` | 图鉴用赭石、朱砂、墨绿,不用明快色 |
| H3 | 正文必须衬线 | 正文与标题均用 serif 族 | 衬线是印刷品的字体骨架 |
| H4 | 禁圆角 | `border-radius` 仅允许用于引线端点圆点 | 图鉴是方正的印刷版面 |
| H5 | 禁投影与发光 | 不得出现 `box-shadow` / `drop-shadow` / 发光 `text-shadow` | 平面印刷品没有立体感 |
| H6 | 禁 emoji 图标 | 渲染产物中章节区不含 emoji 码点 | 与印刷品气质冲突 |
| H7 | 禁深色底 | 纸色明度不得低于 0.86(见 H1) | 深色是 `editorial-mono` 的地盘,本风格必须保持互补 |
| H8 | 正文对比度达标 | `contrast(ink, paper) ≥ 4.5:1` | 可读性底线 |

## 四、高级感判据(软约束,人评)

机器拦不住"合法但难看"。以下由设计部在**生产组上线时**一次性把关:

- **秩序**——引线、编号、分隔线必须对齐到同一套隐含网格,不得随意
- **克制**——accent 只出现在编号、引线端点、少量强调处,不作区块填充
- **纸感**——纸纹强度要能看出肌理但不能脏,过重会显廉价
- **留白**——标本四周必须留足空气,拥挤会失去图版的从容

## 五、边界:宪法 vs 参数空间

| 生产组可自由调 | 生产组不可越界 |
|---|---|
| 纸色的色相/饱和/明度(在 H1 域内)、纸纹强度 | 不得调成纯白、中性灰或深色底 |
| 墨色深浅、accent 色相 | accent 不得高饱和高明度(H2) |
| 字号级差、字距、行距、衬线字体栈 | 不得改用无衬线 |
| 栏数、栏距、页边距、标本尺寸、留白密度 | 分章不得改为色块或卡片容器 |
| 双线的粗细与间距、引线线宽与端点大小 | 不得引入圆角、投影、发光 |

各维度取值域见 `space.json`。参数空间不够用 → 向设计部提案扩展维度;
需要改变上表右列 → 那是**另一套风格**,不是本风格的调教。

## 六、数据契约

复用 kcard 的通用卡片结构(`emoji` / `name` / `nameEn` / `category` /
`themeColor` / `hero` / `blocks[]`),因此**任何已有生产组的 card.json
不加字段即可切换到本风格渲染**,只是不会出现引线标签。

本风格额外支持一个可选字段:

| 字段 | 类型 | 说明 |
|---|---|---|
| `specimenLabels` | array | 引线标签,最多 4 条。每项 `{"text": "...", "side": "left"\|"right"}`。位置由骨架决定,数据不提供坐标——坐标交给 AI 填会不可靠,且会把版式决策泄漏到内容层 |

字段详解见同目录 `schema.md`。

## 七、已知偏离

- **字体依赖 macOS 系统字体**(Songti SC / Baskerville / PT Serif)。
  这是**有意接受的约束,不是待办**——本项目按 macOS 单机渲染设计,
  不追求跨平台一致。代价是换到 Linux/Windows 渲染会 fallback 到别的字体、
  版式与设计稿不符;若哪天需要跨平台,再引入自持字体
  (思源宋体 / Noto Serif CJK,OFL 授权,约 30MB)。
- **hero 素材依赖生产组**:本风格的 `sample.json` 无主图,预览走 emoji 兜底,
  故 E4 标本式构图与 E5 引线标签的实际效果需配真实主图才能完全体现。
