## editorial-mono — 深色编辑排版

**气质**:暗夜画册。视觉张力来自排版层次与克制用色,不来自特效。
**适用**:「一个主体 + 若干信息块」的百科式知识点;希望主体在深底上跳脱的选题。

| | |
|---|---|
| 底色 | 极深近黑(HSL 明度 ≤ 0.12),由主体色的**互补色相**推导,带冷暖倾向 |
| 主轴 | 竖排宋体大标题 + Didot 斜体巨字叠压 |
| 结构 | 细线分章 · 衬线编号 01/02 · 展台椭圆 · 纸感噪点 |
| 用色 | accent 极度克制,只作编号、指标线、微染 |
| 可调 | 32 个维度(色彩 10 / 排版 10 / 版面 6 / 材质 7) |

**骨架**

| 名称 | 构图 | 适用 |
|---|---|---|
| `a-title-left` | 标题竖排在左,主体居中偏右,巨字压右上 | 常规,主体形状规整 |
| `b-type-dominant` | 巨字为主视觉,主体缩至右下角 | 主体形态平淡,或强调概念 |
| `c-hero-bleed` | 主体放大出血到右上,文字轴退到左侧 | 主体质感精良,值得大面积展示 |

**搭配**

| 名称 | 特征 | 预览 |
|---|---|---|
| `classic` | 基准。双栏,标准密度 | [classic.png](styles/editorial-mono/preview/classic.png) |
| `airy` | 单栏长卷,字号放大、留白加厚、噪点几近关闭 | [airy.png](styles/editorial-mono/preview/airy.png) |
| `stark` | 主体出血,底色更深更中性,噪点关闭,行距收紧 | [stark.png](styles/editorial-mono/preview/stark.png) |

**硬约束摘要**(完整 9 条见 [STYLE.md](styles/editorial-mono/STYLE.md))
禁 emoji 章节图标 · 标题必须衬线 · 底色明度 ≤0.12 · accent 必须与底色异色相
· 禁玻璃拟态 · 禁发光 · 禁胶囊圆角 · 正文对比度 ≥4.5

## almanac — 博物图鉴

**气质**:十九世纪纸本图鉴。视觉张力来自印刷工艺的克制与秩序。
**适用**:与 editorial-mono 覆盖同类内容但气质相反;需要标注主体各部位的选题。

| | |
|---|---|
| 底色 | 米色纸(HSL 明度 0.86–0.95,暖色相),纸纹 + 四边暗角 |
| 主轴 | 横排衬线大标题 + 拉丁学名 |
| 结构 | 引线标签 · 罗马编号 I./II. · 双线分隔 · 标本基线 · 目录页式量表 |
| 用色 | 纸色与墨色都是**直接参数**,不由 accent 反推;accent 压到赭石朱砂的朴素范围 |
| 可调 | 34 个维度(纸 5 / 墨 4 / accent 1 / 排版 10 / 版面 6 / 分隔线 3 / 引线 3 / 标本 2) |

**骨架**

| 名称 | 构图 | 适用 |
|---|---|---|
| `a-plate-center` | 标题居上,标本居中,引线标签左右分列 | 正统图版,形态完整的主体 |
| `b-plate-left` | 标本在左作插图,标题与说明在右 | 标题较长,或图文并重 |
| `c-field-note` | 标题压左上,标本推右下,对角构图 | 松弛的手记感,主体形态不规整 |

**搭配**

| 名称 | 特征 | 预览 |
|---|---|---|
| `plate` | 基准。正统图版,居中标本 | [plate.png](styles/almanac/preview/plate.png) |
| `field` | 纸更黄更旧,纸纹与暗角加重,版面收紧,对角构图 | [field.png](styles/almanac/preview/field.png) |

**特有数据字段**:`specimenLabels`(引线标签,最多 4 条)。
不填则不渲染引线,其余照常——**已有生产组的 card.json 不加字段即可切换过来**。

**硬约束摘要**(完整 8 条见 [STYLE.md](styles/almanac/STYLE.md))
纸色必须暖调米色(禁纯白/中性灰/深色) · accent 饱和 ≤0.60 明度 ≤0.65
· 正文必须衬线 · 禁圆角(引线端点除外) · 禁投影与发光 · 禁 emoji 章节图标
· 正文对比度 ≥4.5

## 选型指引

| 你的情况 | 建议 |
|---|---|
| 想要冲击力、主体质感精良、深色调 | `editorial-mono` |
| 想要文献感、需要标注部位、浅色调 | `almanac` |
| 内容条目少而每条较长 | `editorial-mono` / `airy` |
| 内容条目多、需要紧凑排布 | `almanac` / `field` |
| 已有卡片想换个气质试试 | 两套风格数据契约通用,改 `profile.json` 的 `style` + `preset` 即可 |

选定后按 `PLAN.md` 第六节「新增生产组」checklist 建组:
复制 preset 为本组 `profile.json` → 调参 → `style-check.py` 通过 → 出 3 张样卡
→ 设计部签字 → 上线。

## 已知约束与债务(两套风格共有)

- **字体依赖 macOS 系统字体**(约束,非债务):本项目按 macOS 单机渲染设计,
  不追求跨平台一致,故直接用系统衬线字体而不自持字体文件。
  换到 Linux/Windows 渲染会 fallback、版式与设计稿不符。
  若日后需要跨平台,再引入 OFL 授权的思源宋体 / Noto Serif CJK。
- **风格自带 hero 素材缺失**(债务):两套风格的 `sample.json` 均无主图,
  自证预览走 emoji 兜底,故标本构图与引线标签的实际效果需配真实主图才完整体现。
