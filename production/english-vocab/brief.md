# english-vocab 生产组说明

英语单词与词组讲解卡。面向有一定基础、想把词"用对"而不只是"认识"的学习者。

**风格**:`almanac`(博物图鉴) · 搭配 `plate` · 骨架 `a-plate-center`

选它是因为横排衬线标题天然适配拉丁字母词条,纸本词典的气质也对;
`editorial-mono` 的竖排中文大标题放英文单词会很别扭。
风格的视觉规范见 `design/styles/almanac/STYLE.md`,字段定义见同目录 `schema.md`。
**本组不修改风格,只在其参数空间内调教**——需要风格没开放的能力时向设计部提案。

## 字段映射约定

通用卡片结构是为"主体 + 属性面板"设计的,本组把它映射到词条上:

| 通用字段 | 本组用途 | 示例 |
|---|---|---|
| `name` | **单词或词组本身** | `ephemeral` / `break the ice` |
| `category` | **音标 + 词性**,渲染在标题下方 | `/ɪˈfem(ə)rəl/ · adj.` |
| `nameEn` | **词源出处**,斜体拉丁体显示,并出现在页脚 | `ephēmeros · Greek` |
| `emoji` | 词义**意象**,不是装饰 | `ephemeral` → 🍂 |
| `specimenLabels` | **词根构件拆解**,引线指向意象 | `epi- 之上` / `hēmera 日` |
| `themeColor` | **不填**。见下方说明 | — |

`specimenLabels` 只在词根拆解**确有教学价值**时使用(多为拉丁/希腊词源的长词);
日常高频词、习语不必强行拆,留空即可,引线不渲染,版面照常。

**关于 accent 色**:`render.py` 只在卡片配有 `hero` 主图时才自动取色。
本组用 emoji 作词义意象、不配主图,因此 accent 恒为 almanac 的默认朱砂色。
这正合本组需要——**全组色调统一,像同一部词典的内页**,而非每张卡一个颜色。
若日后为某些词条配了真实主图,记得同时显式填 `themeColor` 锁住朱砂色,
否则那几张会因自动取色而与其余卡片脱节。

## 章节编排

固定顺序,缺哪节跳过哪节,不凑数:

| 编号 | 标题 | style | 内容要求 |
|---|---|---|---|
| I | 核心释义 | `list` | 2–3 个义项,按使用频率排序 |
| II | 例句 | `list` | 2–3 句,**必须是完整自然句**,英文在前中文在后用 `——` 分隔 |
| III | 高频搭配 | `tags` | 3–5 个真实搭配,写成 `collocate + word` 的形态 |
| IV | 语域适用度 | `metric` | 口语 / 书面 / 学术三档,percent 表示该语域下的自然度 |
| V | 易混辨析 | `list` | 与近义词的**区别点**,不是同义词罗列 |
| VI | 词源 | `text` | 一句话讲清来历,有故事的优先 |

`span: "full"` 用于 V 和 VI 两节。

## 口吻

- **讲区别,不讲定义**。学习者查得到定义,查不到"什么时候不能用"
- 中文简洁克制,不用"哦""其实呢"这类语气词,也不喊口号
- 例句要像真人会说的话,避免教科书腔("This is a pen")
- 词源部分可以有趣,但不编造——不确定的词源写"来历存疑"而非硬编

## 选词标准

优先收:**认识但用不好**的词。具体是——

- 中高频但语域敏感的词(`ephemeral` 书面味重,口语用会怪)
- 中文对应词模糊、容易误用的词(`procrastinate` vs `delay`)
- 高频习语(`break the ice`),这类查词典最没用,最需要卡片
- 不收:超低频学术词、已被中文完全吸收的外来词

## 产卡命令

```bash
python scripts/style-check.py production/english-vocab          # 改参数后先过闸门
python scripts/render.py production/english-vocab/cards/<slug>  # 出图
```

卡片目录名用单词的小写连字符形式:`ephemeral`、`break-the-ice`。
